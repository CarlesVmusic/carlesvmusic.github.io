COM POSAR-LA A LA WEB ACTUAL
1. Guarda una còpia de la web actual (o descarrega el repositori com a ZIP).
2. Extreu tracks.zip al teu ordinador.
3. Puja el CONTINGUT extret a l’arrel del repositori CarlesVmusic/carlesvmusic.github.io. No pugis el ZIP ni una carpeta que l’embolcalli.
4. Substitueix els fitxers del mateix nom. Inclou les carpetes assets, tracks i musica amb el seu contingut.
5. Conserva el fitxer CNAME actual, el domini personalitzat i la configuració de GitHub Pages. Aquest ZIP no modifica aquests elements.
6. Desa els canvis i espera que GitHub Pages acabi de publicar. Després actualitza el navegador sense memòria cau.
